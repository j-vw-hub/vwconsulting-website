# VWConsulting — eerste websiteversie

Vier responsive pagina’s in HTML, CSS en JavaScript. Geen buildstap of betaalde afhankelijkheden.

## Testen
Open `index.html` in je browser. Voor GitHub Pages: upload de bestanden naar een repository, ga naar Settings > Pages en kies Deploy from a branch, `main`, `/ (root)`. De website verschijnt daarna op de door GitHub aangegeven URL.

## Publiceren bij Antagonist
Upload de inhoud van deze map naar de webroot van je hostingpakket via de bestandsbeheerder of SFTP, na controle van bestaande bestanden en het maken van een back-up. Verander geen DNS- of e-mailrecords zonder controle.

## Nog af te ronden
- Projecten en opdrachtgevers toevoegen.
- Domein, HTTPS en hostingconfiguratie bij Antagonist controleren.

## Opbouw
- Lettertypen (DM Sans, Manrope) staan lokaal in `assets/fonts/`, zodat er geen verbinding met Google nodig is.
- Het contactformulier verstuurt via Web3Forms (account info@vwconsulting.nl); de access key staat in `contact.html`.
- `privacy.html` beschrijft de verwerking via het contactformulier; pas deze aan als er analysetools of cookies bijkomen.

Gebruik GitHub Pages uitsluitend als testomgeving; controleer voorwaarden voor zakelijke hosting.
